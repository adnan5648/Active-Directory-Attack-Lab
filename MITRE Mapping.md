# MITRE 
The ATT&CK mapping summarizes the full attack path from initial access to domain compromise. Each stage is linked to a specific MITRE ATT&CK technique, showing how credential abuse, enumeration, Kerberoasting, privilege escalation, lateral movement, and DCSync combine into a realistic Active Directory attack chain.
